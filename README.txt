# Ganesh Chavithi Website

FREE static website. No database or paid backend is required.

## How to edit

Open `index.html` and find `EDITABLE CONTENT`.

1. Change the celebration name, year, location and organization.
2. Change admin/member names.
3. Put your photos in:
   - images/admins/
   - images/members/
   - images/2026/
   - images/2025/
4. Put videos in:
   - videos/2026/
   - videos/2025/
5. Put your donation QR image at:
   - payments/qr.png
6. Change the UPI ID and contact number in CONFIG.

## Important
A static website cannot permanently upload new files to the public website from a visitor-facing upload button without a server/storage service. The free method is to replace/add files in these folders and update their filenames in CONFIG.

The site is suitable for free static hosting such as GitHub Pages or Cloudflare Pages.
